# Nombre de la aplicación SPA
Jimnasio
## Descripción
Es un proyecto de una página web de un Gimnasio para poder realizar el seguimiento de los entrenamientos de cada cliente. Con capacidad de competir contra otra gente por obtener mejores marcas y conocer gente de marcas parecidas.
## Características Principales
-1 Registrar entrenamientos
-2 Competir con otras personas
-3 Mejorar los entrenamientos con consejos
## Tecnologías Utilizadas
- **Framework:** Angular +22.2.0
- **Lenguaje:** TypeScript
- **Styling:** CSS3
- **Routing:** Angular Router
